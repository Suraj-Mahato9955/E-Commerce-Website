# 🛍️ NovaShop — E-Commerce Website

A modern and responsive e-commerce website built using **HTML, CSS, and JavaScript**.

NovaShop provides a clean shopping experience with product browsing, search and filtering, wishlist management, cart functionality, product details, checkout, and contact pages.

## ✨ Features

### 🏠 Home Page
- Modern hero section
- Featured products
- Shopping categories
- Promotional banner
- Newsletter section
- Responsive navigation

### 🛒 Shopping
- Browse products
- Search products
- Filter products by category
- Sort products by:
  - Price — Low to High
  - Price — High to Low
  - Name — A to Z
  - Name — Z to A

### ❤️ Wishlist
- Add products to wishlist
- Remove products from wishlist
- Wishlist data stored using Local Storage

### 🛍️ Shopping Cart
- Add products to cart
- Increase/decrease quantity
- Remove products
- Automatic cart count
- Automatic total calculation
- Cart data stored using Local Storage

### 📦 Product Details
- Product information
- Product category
- Product rating
- Product price
- Add to cart
- Add to wishlist

### 💳 Checkout
- Customer information form
- Order summary
- Total price calculation
- Simple checkout experience

### 📱 Responsive Design
- Desktop friendly
- Tablet friendly
- Mobile friendly
- Responsive navigation menu

### 📞 Contact
- Contact information
- Contact form
- FAQ section

### 📰 Blog
- Featured article
- Blog cards
- Modern blog layout

### ℹ️ About
- About NovaShop
- Company values
- Statistics section
- Responsive layout
